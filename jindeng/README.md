# 烬灯

> 长夜吞没了山城“雾渡”，所有灯都熄了，熄了灯的人会慢慢变成影子。
> 你是城里最后一个学徒灯匠阿烬，提着师父留下的旧灯笼上山，点亮三座守夜灯塔，再登上长明台找到失踪的师父。

一个带剧情的 2D 像素动作 RPG。纯 HTML5 Canvas + 原生 JavaScript，零依赖、不用安装、不用构建，美术和声音全部用代码现场生成。

---

## 怎么开始

1. 双击 `index.html`，用浏览器打开（推荐 Chrome / Edge / Firefox 的新版本）。
2. 在标题画面点 **新的长夜**。之后回来玩点 **继续**。
3. 浏览器规定页面要先被点一下或按一个键才能出声，所以声音会在你第一次操作之后才出现。

游戏在灯塔**自动存档**（点亮灯塔、在灯塔休息、死亡复活时都会存）。存档放在浏览器的本地存储里，换浏览器或清除网站数据会丢失。

## 操作

| 操作 | 作用 |
|---|---|
| **WASD**（或方向键） | 移动 |
| **鼠标位置** | 朝向和攻击方向（画面上的小准星） |
| **鼠标左键** | 灯笼挥击，连点打出三段连招（第三段最重） |
| **长按左键 1 秒** | 光爆：消耗 15 灯油，震开周围的影子并让它们僵直 2 秒，还能点燃火盆 |
| **鼠标右键** | 当前副能力，朝鼠标方向释放（冲刺 / 钩索 / 投火） |
| **鼠标滚轮** | 切换副能力 |
| **空格** | 翻滚（朝移动方向，没在移动就朝鼠标方向）。前 0.2 秒无敌 |
| **E** | 交互：对话、开宝箱、点灯塔、捡东西、敲钟 |
| **F** | 喝一碗暖汤，回 2 颗心 |
| **Esc** | 暂停菜单：装备、物品、地图、任务、设置 |

对话和菜单都可以用鼠标点击，也可以用 E 或空格继续，选项还可以按 1/2/3。每个按键第一次需要用到时，屏幕下方会提示一次。

切到别的窗口时游戏会自动暂停（不会弹出菜单），回来后点一下画面或按 Esc 就能继续。

## 大致流程（不剧透）

- **序章 · 熄灯夜**：在师父的灯坊醒来，拿起旧灯笼，跟着小满上街，第一次和影子交手，然后去镇口点亮第一座灯塔。
- **第一章 · 竹影林**（镇口往西）：夜里的竹林。萤火虫是会移动的光源，跟着它们走能少耗油。
- **第二章 · 沉钟湖**（下坊往东）：结冰的湖。冰面会滑，敲响小钟能让冰面冻上或裂开。
- **第三章 · 窑火坡**（石阶街往南）：废弃的瓷窑。烟会挡光；把陶罐推到熔岩口上能让熔岩冷却。
- **终章 · 长明台**（镇口往北）：三座守夜灯塔都亮了，石门才会打开。

每打倒一个 Boss 会得到一个新能力，回到旧地图能开出新路，拿到隐藏的奖励：

| Boss | 打败后获得 | 能做什么 |
|---|---|---|
| 竹中客 | **冲刺** | 越过裂缝和窄水道，冲刺中无敌 |
| 溺钟 | **钩索** | 勾住灯柱飞过深渊，或把小怪拉过来 |
| 窑神 | **投火** | 点燃远处的火盆、烧掉藤蔓、打碎陶兵的盾和窑神的瓷甲 |

**三条支线**：茶铺的猫（小满拜托）、送油（老枫拜托，给镇上 5 户熄灯的人家送灯油）、老枫的灯罩（三个区域各找一样材料）。

### 小贴士

- **光就是资源**：左上角黄条是灯油。暗处每秒耗油，站在灯塔、火盆、萤火虫的光里会回油。灯油烧光后每 3 秒掉 1 点血，屏幕边缘会伸出影子的手。
- **影子怕光**：普通影子在暗处伤害 +50%。先用光爆点亮附近的火盆，再在光里打它们。
- **完美闪避**：在敌人出手的瞬间翻滚，会触发 0.3 秒慢动作。
- **Boss 都有明确预兆**：地上的红线、红圈都是在告诉你“马上要打这里”。Boss 的名字和血条在屏幕上方。
- **窑神的瓷甲**：每一下都能把瓷甲敲出裂纹（血条下面的“瓷甲”条会变短），第三段最狠。四块全碎后它会跪地 4 秒，这是输出的好时机；二阶段它会重新长出两块，再敲碎一次就会再跪一次。
- 敌人会掉**灯芯**，拿去镇上石阶街的老枫灯铺换暖汤上限、灯油上限、灯罩和护符。
- 死了会回到最后休息的灯塔，身上一半的灯芯会掉在死的地方，回去就能捡回来（再死一次就没了）。
- 暂停菜单里的地图只显示去过的房间，黄色是点亮的灯塔，红色是还没打过的 Boss 房。

## 我自己做的决定（文档没写清楚的地方）

1. **两种灯塔**：每个区域入口是“守夜灯塔”，Boss 房门口是“灯台”，都能存档、回血、补汤、互相传送。“三座守夜灯塔”指竹影林、沉钟湖、窑火坡入口的那三座。镇口和长明台下也各有一座。
2. **“Boss 战拉远一点”**：画面固定是 480×270 的像素画，缩放会破坏像素感，所以每个 Boss 场地都正好一屏大。打 Boss 时镜头固定在场地中央，整个场地都在画面里。
3. **冲刺距离跟着鼠标**：冲刺的距离等于到鼠标的距离（40~74 像素），方便准确地落在窄台子上。
4. **“亮区”只算环境光**：灯塔、火盆、萤火虫、月光、送过油的人家窗户都算，自己的灯笼不算。不然灯笼永远照着自己，暗处加成就永远不会生效。
5. **影子在暗处 +50% 只对普通敌人生效**，Boss 不吃这个加成。实测加上之后第一个 Boss 太难。
6. **室内（灯坊、茶铺）不耗灯油**。
7. **敌人重生**：在灯塔休息或者死亡后普通敌人会重新出现；精英和 Boss 只打一次。
8. **死亡复活也会存档**：已经打倒的 Boss、拿到的东西不会因为死亡而丢失，只有一半灯芯会掉在原地。
9. **窑火坡的回头路**：窑火坡是最后一个区域，后面没有新能力了，所以它的两处秘密要用本区 Boss 给的“投火”回来开。
10. **选择一（冰里的影子）不能反悔**：选了“不救”影子就会沉下去。灯油不够 50 时可以先离开，回头再来。
11. **精英**：每个区域各一只，终章塔身也有一只；前三只必掉心之碎片，塔身那只掉护符。
12. **送油支线**：老枫直接给你 5 瓶灯油；送完 5 户回去找他，奖励纸灯罩。猫支线奖励慢时符；灯罩支线奖励青灯罩。
13. **隐藏 Boss“长夜”**：师父在旁边帮你点火盆（先点离你近的）、朝它打光弹。长夜只有被光照着时才吃满伤害，否则只吃三分之一。它会主动飘去“吞”亮着的火盆，吞光的那 4~5 秒一直被火光照着，是最主要的输出窗口；光爆照亮 5 秒，师父的光弹照亮 2.5 秒。被照亮时它身上有金色轮廓，顶部血条下面写着“被照亮 / 在暗处”。
14. **中文文字**按屏幕的实际分辨率绘制，不是像素字体。480×270 下的像素中文很难读。
15. **画面缩放**按设备像素取整数倍，像素始终清晰；窗口比例不是 16:9 时四周会有黑边。
16. **敌人掉落**：灯芯 65% 概率掉，灯油瓶 14%。灯笼鬼第一次被打中必掉灯油瓶，因为它偷油。
17. **Boss 战后结算**：Boss 战开始时出口就锁上（站在门口也会被挪进场地）。Boss 倒下后出口继续锁着，掉的灯芯会自动飞过来，接着加心、放战后台词、给能力，全部放完才开门。结算挂在 Boss 房上，不用定时器；万一中途离开（比如调试传送），回到 Boss 房会从头补放，心不会重复给。
18. **操作提示绑定房间**：提示只在触发它的房间里显示。换了房间、开始对话，或者排队超过 8 秒，没显示的提示就作废；条件再满足时会重新出现。只闪了不到 1.5 秒的提示不算看过。拿到新能力时，横幅本身就是说明；滚轮切换的提示会在之后的房间里补上。
19. **窑神的瓷甲**：每块 7 点，普通挥击按伤害扣，第三段 ×1.5，光爆 2 点，投火 4 点，最低扣到 0。四块全碎后跪地 4 秒，这期间伤害 ×1.25；二阶段头和胸的瓷甲会重新长出来。窑神不会追进墙角。
20. **溺钟打完后湖面重新冻上**，不用再跳浮冰离开。
21. **掉进熔岩**会回到上一个安全点；如果那里已经被熔岩淹了（窑神二阶段），就换到最近的安全地面，不会原地连续掉下去。
22. **灯芯结局里死在长夜手里**：复活后回到长明台顶，会重新放师父战后的选择，可以再挑一次。
23. **杂兵数值**：小影血量 6→7、更快一点、扑得更远；影犬血量 5→6；竹林深处（b3、b8）各多一只小影。同一个机器人在竹林口的掉血大约多了四成。
24. **竹中客**：一阶段的突进从三段改成两段，二阶段仍是三段，突进后的间隔也短了一点。分身 7 秒后自己散掉，之后每轮只出两个。

## 已知问题和取舍

- 只在 Chromium 内核的无头浏览器里实测（软件渲染，1080p 下最重的场景也是 60 帧）。Safari 和 Firefox、真机都没试过。
- 音乐和音效都是代码合成的，我没法亲耳听，只确认了播放时没有报错。觉得吵可以在“设置”里分别调总音量、音乐、音效。
- 难度是用简单的自动战斗机器人估的：竹中客机器人 6 次赢 5 次；后面的 Boss 用正常进度的装备（多 2 颗心、5 碗汤、铁灯罩）时，溺钟 6/6、窑神 4/4、师父 4/4，长夜 5 次赢 4 次（机器人全程没喝汤）。湖心 Boss 二阶段要用冲刺在浮冰间移动。
- 不开无敌、只按主线走（不收集心之碎片）时，机器人能从序章一路打到窑神并拿到投火，但会死不少次。主要是它不会引怪，喝汤时机也差；只带 6 颗心去打溺钟对它最难。真人应该会轻松一些，没有真人实测过。
- 一周目时长按房间数和剧情量估计在 60~90 分钟，没有真人从头到尾计时验证过。
- 敌人的追击是直线追，偶尔会被墙角卡住。
- 不支持手柄，也不能改键。
- 部分浏览器在 `file://` 下可能不允许本地存储（比如 Safari 的某些隐私设置），这时休息会提示“存档失败”，游戏照样能玩，只是不能继续。

## 文件结构

```
index.html        入口（按顺序加载下面这些普通 script）
js/config.js      所有手感和难度数值
js/art.js         代码生成的像素贴图、头像、地砖、结局插画
js/audio.js       WebAudio 合成音效和每个区域的循环配乐
js/maps.js        34 个房间（字符网格 + 实体列表）
js/data.js        敌人、Boss、装备、物品、商店、任务日志
js/story.js       全部剧情对话、NPC 对话、结局文字
js/engine.js      输入、镜头、碰撞、房间切换、存档
js/light.js       光照
js/combat.js      主角、副能力、敌人 AI、Boss
js/ui.js          HUD、对话框与剧情脚本、菜单、标题、结局
js/main.js        主循环、场景切换、调试
```
